## TIPOS DE TOOLS (6.1.1)

- Test management (Jira, TestRail)
- Test design & implementation
- **Static analysis** (linter, SonarQube)
- **Test execution** (Selenium, Playwright, Postman)
- Test data preparation
- Performance testing (JMeter, k6)
- Test support (coverage)
- Test monitoring

## BENEFITS DE TEST AUTOMATION (6.2.1)

✅ Velocidad
✅ Repetibilidad
✅ Reusabilidad
✅ Consistencia
✅ Mayor coverage
✅ Feedback rápido

## RIESGOS (6.2.1)

⚠️ Falsa sensación 100% coverage = no bugs
⚠️ Mantenimiento alto (cambios UI rompen scripts)
⚠️ Costos iniciales altos
⚠️ Requiere skills específicas
⚠️ No reemplaza humanos para UX/exploratory

## CATEGORÍA MNEMOTÉCNICA

"Mngr-Design-Static-Execution-Data-Support-Mon"
→ herramientas de gestión, diseño, análisis, ejecución, datos, soporte, monitoreo.

## KEY POINTS

- **NO todo se automatiza:** tests exploratorios/UX son humanos
- **Tools son ASSISTENCIA, no reemplazo**
- **Tool adoption:** piloto + ROI + curva de aprendizaje
