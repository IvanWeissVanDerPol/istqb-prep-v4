## 📘 Sobre el syllabus v4.0.1

**Cambios importantes desde v3.1 (2018):**

1. **ISO 25010 actualizado (2023):** "usability" → "interaction capability", "portability" → "flexibility", agregado "safety"
2. **Cap 4 rediseñado:** se agregó Sección 4.5 "Collaboration-based Test Approaches" (NUEVO)
3. **DevOps + Shift left incorporados** como conceptos oficiales (Cap 2.1.4-2.1.5)
4. **Test Pyramid y Testing Quadrants** (Cap 5.1.6-5.1.7) ahora son material oficial
5. **User Stories + ATDD** (Acceptance Test-Driven Development) en Cap 4.5.3
6. **Vocabulario unificado:** "documentation" → "work products", "stages" → "phases", "white box" → "white-box"
7. **Tiempo de instrucción oficial:** 1135 min (~19 horas) — dividido en:
   - **Cap 1:** Fundamentals — 180 min
   - **Cap 2:** SDLC — 130 min
   - **Cap 3:** Static — 80 min
   - **Cap 4:** Test Analysis & Design — 390 min ← más pesado
   - **Cap 5:** Managing Test — 335 min
   - **Cap 6:** Tools — 20 min

**Lectura detallada de cambios:** ver `09_v4_changes/`

## 🎓 Estructura del examen CTFL (oficial, igual en v4)

- **40 preguntas** opción múltiple (casi todas con 4 opciones, a veces 5)
- **60 min** + 15 min si el idioma no es tu nativa
- **65% nota mínima** (26/40 correctas)
- **Acreditado por 5 años** (en algunas versiones lifetime, verificar con tu Member Board)
- **Idiomas:** inglés, español (LATAM), portugués, alemán, francés y +20

## ✅ Cómo usar este repo

1. Empezá por `01_plan_estudio/00_vision_general.md`
2. Descargá el **syllabus oficial v4.0.1** desde https://istqb.org (gratis, 78 pp PDF)
3. Leé `02_syllabus_v4_0_1/` para entender la **estructura** (no es substituto del PDF)
4. Hacé los **quizzes** después de cada capítulo en `06_practice_tests/`
5. **Semana 7:** rendí los **sample exams completos** (60 min cronometrados)
6. **Última semana:** glosario + flashcards
