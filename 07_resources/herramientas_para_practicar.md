## Para practicar técnicas de testing (Cap 4)

### Aplicaciones de prueba gratuitas (deploy local)

- **OWASP Juice Shop** — vulnerable por diseño, ideal para testing
- **DVWA (Damn Vulnerable Web App)** — security testing
- **Google Gruyere** — bugs intencionales
- **Buggy Web App** — testing basics

### JSONplaceholder / REST API testing

- **JSON Server** — fake REST API local
- **httpbin.org** — testing HTTP calls
- **Petstore Swagger** — OpenAPI
