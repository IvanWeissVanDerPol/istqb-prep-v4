### **Capítulo 1 — Fundamentals of Testing (180 min)**

**1.1 What is Testing?**
- 1.1.1 Identify typical test objectives (K1)
- 1.1.2 Differentiate testing from debugging (K2)

**1.2 Why is Testing Necessary?**
- 1.2.1 Exemplify why testing is necessary (K2)
- 1.2.2 Recall the relation between testing and quality assurance (K1)
- 1.2.3 Distinguish between **root cause**, **error**, **defect**, and **failure** (K2) ⭐

**1.3 Testing Principles**
- 1.3.1 Explain the **seven testing principles** (K2) ⭐⭐

**1.4 Test Activities, Testware and Test Roles**
- 1.4.1 Explain the different test activities and related tasks (K2)
- 1.4.2 Explain the impact of context on the test process (K2)
- 1.4.3 Differentiate the testware that support the test activities (K2)
- 1.4.4 Explain the value of maintaining traceability (K2) ⭐
- 1.4.5 Compare the different roles in testing (K2)

**1.5 Essential Skills and Good Practices in Testing**
- 1.5.1 Give examples of the generic skills required for testing (K2)
- 1.5.2 Recall the advantages of the whole team approach (K1)
- 1.5.3 Distinguish the benefits and drawbacks of independence of testing (K2)

### **Capítulo 2 — Testing Throughout the SDLC (130 min)**

**2.1 Testing in the Context of a SDLC**
- 2.1.1 Explain the impact of the chosen SDLC on testing (K2)
- 2.1.2 Recall good testing practices that apply to all SDLCs (K1)
- 2.1.3 Recall the examples of test-first approaches to development (K1) — BDD, TDD, ATDD
- 2.1.4 Summarize how DevOps might have an impact on testing (K2) ⭐ **NUEVO**
- 2.1.5 Explain shift left (K2) ⭐ **NUEVO**
- 2.1.6 Explain how retrospectives can be used as a mechanism for process improvement (K2) ⭐ **NUEVO**

**2.2 Test Levels and Test Types**
- 2.2.1 Distinguish the different **test levels** (K2) ⭐
  - Component, Component Integration, Integration, System, Acceptance
- 2.2.2 Distinguish the different **test types** (K2) ⭐
  - Functional, Non-functional (incl. ISO 25010:2023: interaction capability, flexibility, safety), Structural, Change-related
- 2.2.3 Distinguish confirmation testing from regression testing (K2) ⭐

**2.3 Maintenance Testing**
- 2.3.1 Summarize maintenance testing and its triggers (K2)

### **Capítulo 3 — Static Testing (80 min)**

**3.1 Static Testing Basics**
- 3.1.1 Recognize types of **work products** that can be examined by static testing (K1) ⭐
- 3.1.2 Explain the value of static testing (K2)
- 3.1.3 Compare and contrast static testing and dynamic testing (K2) ⭐

**3.2 Feedback and Review Process**
- 3.2.1 Identify the benefits of early and frequent stakeholder feedback (K1)
- 3.2.2 Summarize the activities of the review process (K2) ⭐
- 3.2.3 Recall which responsibilities are assigned to the principal roles when performing reviews (K1) ⭐
  - **Roles:** author, moderator, reviewer, scribe, manager
- 3.2.4 Compare and contrast the different review types (K2) ⭐
  - **Walkthrough** vs **Technical review** vs **Inspection**
- 3.2.5 Recall the factors that contribute to a successful review (K1)

## 📊 Resumen de niveles K

**Niveles cognitivos (Bloom adaptado por ISTQB):**
- **K1** (Recall): reconocer, recordar — total **14 K1 LOs**
- **K2** (Understand/Apply): explicar, distinguir, comparar — total **42 K2 LOs**
- **K3** (Apply in context): **usar** una técnica (no solo explicarla) — **5 K3 LOs** específicas:
  - 4.2.1 EP (K3) ⭐⭐
  - 4.2.2 BVA (K3) ⭐⭐
  - 4.2.3 Decision Table (K3) ⭐
  - 4.2.4 State Transition (K3) ⭐
  - 4.5.3 ATDD (K3) ⭐
  - 5.1.4 Estimation (K3)
  - 5.1.5 Prioritization (K3)

**Las preguntas K3 son las que más cuestan**, porque requieren aplicación práctica.
