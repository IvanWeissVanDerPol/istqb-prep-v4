# 💼 QA Career Paths — Roles, Salaries (PY vs Global), Progression

> **Documento de orientación profesional** — qué roles existen en QA, cómo se evoluciona, y cuánto se paga en Paraguay vs LATAM vs US/EU.
>
> **Para quién:** tu grupo de amigos, pensando en esto como carrera a largo plazo, no solo certificación.

---

## 📊 Resumen ejecutivo

- **La demanda de QA está creciendo 25% hasta 2032** (BLS — US Bureau of Labor Statistics).
- **En Paraguay** un QA Tester junior gana **₲9.6M/año** según Glassdoor (≈ USD 1,300/año al cambio paralelo — números muy bajos vs LATAM).
- **En LATAM remoto** un QA mid/senior puede llegar a **USD 4,000-7,000/mes** (USD 48-84K/año) si trabaja para empresa US.
- **ISTQB CTFL NO es suficiente** por sí sola — es la puerta de entrada, no la certificación que te hace ganar bien.
- **La automatización es el multiplicador salarial** (15-25% premium vs manual).

## 🎯 Roles QA — Los 8 principales

### 1. **Junior QA / QA Analyst** (0-2 años)

**Qué hacés:**
- Ejecutar test cases
- Reportar bugs
- Exploratory testing guiado
- Regression manual

**Skills esenciales:**
- Test case design (BVA, EP)
- Bug reporting (Jira, Azure DevOps)
- SQL básico
- Git fundamentals
- HTML/CSS + Browser DevTools
- HTTP/HTTPS basics

**Salario esperado 2025-2026:**

| Mercado | Salario anual |
|---|---|
| 🇵🇾 Paraguay (Asunción) | ₲9.6M - ₲24M (USD 1,300 - 3,300) |
| 🇦🇷 Argentina | USD 12K - 24K |
| 🇧🇷 Brasil | BRL 36K - 72K (USD 7K - 14K) |
| 🇲🇽 México | MXN 240K - 480K (USD 13K - 26K) |
| 🌎 LATAM remoto (US employer) | USD 24K - 48K |
| 🇺🇸 USA (junior) | USD 55K - 80K |
| 🇪🇺 EU | €30K - 50K |

**Para avanzar:** automatizar (incluso tareas básicas).

---

### 2. **Mid-Level QA Engineer** (2-5 años)

**Qué hacés:**
- Own test strategy for features
- Diseñar test suites
- Contribuir a automatización
- Cross-functional con devs/PMs

**Skills:**
- Programación (Python, JS, Java, C#)
- Test automation frameworks (Playwright, Selenium, Cypress)
- API testing (Postman, REST Assured, Supertest)
- CI/CD (Jenkins, GitHub Actions)
- Performance testing (JMeter, k6 — básico)

**Salario 2025-2026:**

| Mercado | Salario anual |
|---|---|
| 🇵🇾 Paraguay | ₲24M - ₲60M (USD 3,300 - 8,200) |
| 🌎 LATAM remoto (US employer) | USD 48K - 84K |
| 🇺🇸 USA | USD 80K - 120K |
| 🇪🇺 EU | €50K - 80K |
| **Premium LATAM automation** | **USD 60K - 110K** (+15-25%) |

**Para avanzar:** profundizar technical + ownership de testing strategy + mentoring juniors.

---

### 3. **Senior QA Engineer / Senior SDET** (5-8 años)

**Qué hacés:**
- Defines test strategy for team/product area
- Builds automation frameworks
- Influence engineering practices
- Mentor juniors/mid-levels

**Skills:**
- Framework architecture (page objects, fixtures)
- Performance + load testing
- System architecture understanding (microservices, APIs, DBs)
- Test infrastructure (CI/CD design, test env management)
- Mentoring

**Salario 2025-2026:**

| Mercado | Salario anual |
|---|---|
| 🇵🇾 Paraguay | ₲60M - ₲120M (USD 8,200 - 16,500) |
| 🌎 LATAM remoto (US employer) | USD 80K - 140K |
| 🇺🇸 USA | USD 120K - 170K |
| 🇪🇺 EU | €70K - 110K |
| 🇺🇸 FAANG | USD 180K - 280K+ |

---

### 4. **Staff QA / QA Lead** (8-12 años)

**División en 2 paths:**

#### Path A — Technical Track: QA Architect / Principal Engineer
- Quality vision para la organización
- Test infrastructure que sirve cientos de engineers
- Custom tooling
- Open source contributions
- **Salario US: USD 200K - 280K+**

#### Path B — Management Track: QA Manager / Director
- Hire, mentor, manage
- Quality strategy + budget
- Cross-team stakeholder management
- **Salario US: USD 180K - 260K+**

---

### 5. **Roles especializados** (algunos pueden tomarse antes)

#### Performance Engineer
- Load testing, stress testing, scalability
- Tools: JMeter, k6, Gatling, Locust
- **Premium:** +20-30% sobre QA general

#### Security Tester
- Penetration testing, OWASP
- Tools: Burp Suite, OWASP ZAP, Snyk
- Certs adicionales: CEH, OSCP
- **Premium:** +25-40% sobre QA general

#### SDET (Software Development Engineer in Test)
- Híbrido dev + tester
- Construye frameworks complejos
- **Premium:** +15-25% sobre QA general

#### Accessibility Tester
- WCAG, ARIA, screen readers
- Cert: IAAP CPACC
- Demanda creciente

#### Test Manager / Test Lead
- Coordination + strategy
- Reporting a stakeholders
- Cert: ISTQB CTAL-TM

## 💡 Estrategia para Paraguay — Maximizar salario

### 1. Certs que importan (en orden)

| Cert | Cuándo | Por qué |
|---|---|---|
| **ISTQB CTFL** | Mes 1-2 | Puerta de entrada, base teórica |
| **Inglés B2/C1** | Paralelo | Habilita empresa remota |
| **Playwright/Selenium cert** (vendor) | Mes 4-6 | Aumenta chances remote |
| **AWS Cloud Practitioner** | Mes 8-10 | Diferenciador en cloud |
| **CTAL-TA o CTAL-TAE** | Año 2 | Senior roles |
| **CT-GenAI** (NEW 2025) | Año 2 | Mercado AI en explosión |

### 2. Plataformas para trabajo remoto

- **Toptal** — exigente pero bien pago
- **Upwork** — freelance
- **Arc.dev** — start-ups US
- **Crossover** — full-time remote US
- **Turing** — full-time remote US
- **Deel/Remote.com** — aggregators
- **LinkedIn Remote Jobs filter**

### 3. Stack más demandado 2025-2026

- **Playwright** (reemplazando a Selenium como standard)
- **TypeScript** (más demandado que JavaScript puro)
- **Python** (para tools y scripts)
- **k6** (performance moderno vs JMeter)
- **Postman/Newman** (API)
- **GitHub Actions** (CI/CD)
- **Docker basics** (para tests)

## 📈 Roadmap personalizado para tu grupo

### Fase 1: Foundation (Meses 1-3)
- ISTQB CTFL
- Inglés B2
- Manual testing mastery
- Git + SQL básico

### Fase 2: Automation (Meses 4-9)
- Programación (Python o JS)
- Playwright/Selenium
- API testing (Postman)
- CI/CD basics
- **Primer trabajo junior remoto o local**

### Fase 3: Specialization (Meses 10-18)
- Elegir: Performance / Security / SDET / Accessibility
- Cert vendor (Playwright/AWS/k6)
- Contribuir open source
- **Salario target: USD 50K-80K remoto**

### Fase 4: Senior (Años 2-5)
- CTAL-TA o CTAL-TAE
- Framework design
- Mentoring
- Publicar blog/conferencias
- **Salario target: USD 100K-150K remoto**

### Fase 5: Leadership (Años 5+)
- Staff/Principal/Director
- CTEL-TM o CTEL-ITP
- Industry recognition
- **Salario target: USD 180K-280K+**

## ⚠️ Notas honestas sobre las cifras

- **Salarios Paraguay:** limitados, la fuente es Glassdoor (sesgada hacia empresas formales). Hay muchos QA freelance que ganan más fuera de Glassdoor.
- **Salarios LATAM remoto:** muy variables. Cifras de Teilur ($4K+/mes) son para LATAM senior full-time, no entry-level.
- **USD/₲ ratio:** cambia. Verificar al momento de negociar (BCP, paralelo, etc).
- **Conversiones mostradas** son aproximadas a tasa actual.
