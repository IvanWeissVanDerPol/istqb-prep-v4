## ⚠️ Advertencias

### Lo que NO usar:

- **"Dumps"** (preguntas memorizadas filtradas). ISTQB rota preguntas; no aprenderás.
- **Material sin verificar versión.** Si dice v3.1, descartar (excepto para conceptos base).
- **Sitios web con muchos ads** — pueden tener preguntas incorrectas.
- **Videos de 2019-2021** sin verificar versión. Muchos enseñan v3.1.

### Lo que SÍ verificar antes de usar:

- **Fecha de última actualización:** debería ser 2023+ para CTFL v4.0.
- **Versión mencionada:** debe decir "v4.0" o "v4.0.1".
- **Cantidad de stars/forks:** indicador de calidad community.
- **Issues abiertos:** si tiene issues sin responder mucho tiempo, cuidado.
