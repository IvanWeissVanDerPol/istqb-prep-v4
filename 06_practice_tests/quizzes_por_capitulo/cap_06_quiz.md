# Quiz Cap 6 (v4.0.1) — Test Tools

> **8 preguntas** — meta: **≥75% (6/8)**
> Tiempo: 8 min

---

**Q1. (LO 6.1.1) ¿Cuál NO es un tipo de test tool?**

A) Test management.
B) Test execution.
C) Static analysis.
D) Calendar tool.

<details><summary>✅</summary>D. Calendar tool no es una test tool.</details>

**Q2. (LO 6.2.1) ¿Cuál es un beneficio típico de test automation?**

A) Eliminar todos los bugs.
B) Velocidad y repetibilidad para tests repetitivos.
C) Reemplazar al tester humano.
D) Eliminar la necesidad de specs.

<details><summary>✅</summary>B. Automation brilla en tests repetitivos (regression smoke).</details>

**Q3. (LO 6.2.1) ¿Cuál es un RIESGO típico de test automation?**

A) Tests más rápidos.
B) Mantenimiento alto y falsa sensación de 100% coverage.
C) Menos bugs.
D) Documentación automática.

<details><summary>✅</summary>B. Mantenimiento alto es el riesgo #1 de automation.</details>

**Q4. (LO 6.1.1) ¿Cuál es un ejemplo de static analysis tool?**

A) Selenium WebDriver.
B) ESLint.
C) JMeter.
D) Postman.

<details><summary>✅</summary>B. ESLint es linter, hace static analysis. Selenium/Postman/JMeter ejecutan.</details>

**Q5. (LO 6.1.1) ¿Cuál es una herramienta típica de API testing?**

A) Playwright UI.
B) Postman / Insomnia.
C) JMeter UI.
D) Jira.

<details><summary>✅</summary>B. Postman / Insomnia son herramientas de API testing.</details>

**Q6. (LO 6.2.1) Test automation es especialmente útil para:**

A) Tests exploratorios con bugs visuales.
B) Tests de UX.
C) Regression tests repetitivos.
D) Tests únicos.

<details><summary>✅</summary>C. Regression scripts son perfectos para automation.</details>

**Q7. (LO 6.1.1) La decisión de qué herramienta usar depende de:**

A) Madurez, fit con el proceso, licencia, soporte.
B) Solo licencia.
C) Solo estética.
D) Solo popularidad.

<details><summary>✅</summary>A. Tool selection: madurez, fit, costo, licencia, soporte, training.</details>

**Q8. (LO 6.2.1) ¿Qué significa "pesticide paradox" relacionado a tools?**

A) Que los tools no son confiables.
B) Que los mismos tests automatizados dejan de encontrar nuevos bugs.
C) Que los tools cuestan mucho.
D) Que los tools reemplazan humanos.

<details><summary>✅</summary>B. Pesticide paradox aplica también a automation: scripts que no se actualizan dejan de encontrar bugs.</details>
