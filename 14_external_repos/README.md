## ⚠️ Calidad check (cómo evaluar un repo)

Antes de usar un repo como recurso de estudio:

1. **⭐ Stars + 🐛 Issues** — más stars = más confiable; sin issues abiertos sin responder = OK
2. **📅 Last commit** — debería ser 2023+ para CTFL v4.0
3. **📜 License** — MIT/Apache = OK; "Educational only" = cuidado
4. **📚 Syllabus version mentioned** — v4.0 / v4.0.1 / 2018 / v3.1 — saber qué versión
5. **👤 Author credibility** — múltiples contribuidores > single
6. **📖 README clarity** — bien estructurado vs caótico
7. **🧪 Working code** — si tiene scripts, ¿corren?
