## 🎯 What this file is for

When external contributors start submitting pull requests (PRs) to this repo, this file will list them with their contributions:

- Code / content contributions (file added, bug fixed, typo corrected)
- Issue reports that led to a fix
- Reviews that materially improved a PR
- Translations (EN ↔ ES, EN ↔ PT)
- Curriculum feedback (especially from ISTQB-certified testers)

---

## 📋 How to get listed here

1. Open a PR with any change (typo, content addition, new exercise, fix)
2. Add a line under the **Active Contributors** section below with: name, contribution type, date
3. A maintainer reviews and merges — your contribution goes into `CHANGELOG.md` and this file
