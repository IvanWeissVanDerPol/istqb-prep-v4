---

## 📥 Cómo importar

### Anki (recomendado)
1. Abrir Anki
2. File → Import
3. Seleccionar `flashcards_v4.0.1.csv`
4. Tipo de nota: **Basic**
5. Mapear: field 1 → Front, field 2 → Back
6. Tags automáticos desde columns `chapter` y `LO`

### Quizlet
1. Crear nuevo set
2. Import → CSV
3. Primer término = front, segundo = back

### Mochi
1. New card → Import
2. CSV format → import

### RemNote
1. Importar como flashcards rem
