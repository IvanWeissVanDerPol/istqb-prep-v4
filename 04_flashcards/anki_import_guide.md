# Anki Import — Paso a paso

1. **Install Anki** (https://apps.ankiweb.net)
2. **Create a new Deck** → "ISTQB CTFL v4.0.1"
3. **File → Import**
4. Select `flashcards_v4.0.1.csv`
5. Settings:
   - **Note type:** Basic
   - **Deck:** ISTQB CTFL v4.0.1
   - **Field mapping:**
     - Field 1 → Front (text)
     - Field 2 → Back (text)
     - Field 3 → Tags (LOWER)
     - Field 4 → Tags (LOWER)
6. **Import**
7. Verify fields look right
8. Study → Start reviewing

## ⚙️ Suggested Anki settings

- **New cards per day:** 20-30 (sustainable para 8 semanas)
- **Maximum interval:** 90 días
- **Starting ease:** 2.5 (default)
- **Learning steps:** 1min 10min (default)

## 🎯 Daily routine

- 30 min/day Anki review
- Cover all chapters ~85 cards / 30 cards/day = review completo en ~3 días
- Reserve weekend para practice tests

## 🔗 Tags utiles para filtros

Anki te deja filtrar por tag. Combiná:
- `cap:1` — solo Cap 1
- `lo:1.3.1` — solo los principios
- `k3` — solo técnicas que requieren apply
