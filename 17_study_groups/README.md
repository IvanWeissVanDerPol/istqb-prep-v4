## 📞 Formato de sesión semanal (60-90 min)

### Estructura sugerida

```
00:00-00:10  Welcome + objetivo del día
00:10-00:30  Repaso conceptual (1 persona presenta el cap)
00:30-00:45  Quiz rápido (oral, 5 preguntas)
00:45-01:10  Dudas + discusión
01:10-01:25  Mini-práctica hands-on (ej: construir decision table)
01:25-01:30  Asignación próxima semana
```

### Roles rotativos

- **Facilitador:** Lleva la sesión (rotar cada semana)
- **Timekeeper:** Controla tiempos
- **Note-taker:** Captura dudas recurrentes y las pone en un doc compartido
- **Tech support:** Comparte pantalla, comparte links

### Herramientas

- **Video:** Zoom / Google Meet / Discord
- **Pantalla compartida:** Para mostrar quiz + tabla
- **Doc compartido:** Google Doc para notas grupales
- **Anki shared deck:** Pueden compartir mazo de flashcards

## 🏆 Tips para mantener motivación

### Antes de empezar

- **Suscripción a ASOLINFO** — agendar examen real (deadline = motivación)
- **Inversión financiera** — USD 150-300, no querer perder
- **Group commitment** — decir en voz alta "rindo el X fecha"

### Durante

- **Compartir progreso** — wins en el grupo
- **Ayudar a otros** — enseñar refuerza tu conocimiento
- **No caer en perfectionism** — 80% en quiz está OK

### Después del primer fail (si pasa)

- **Normal:** 25-30% fail rate
- **No es personal:** ISTQB cambia preguntas, a veces injusto
- **Reintentá:** Hay descuentos second attempt en algunos boards
- **Analizá:** Qué falló, ajustar plan
