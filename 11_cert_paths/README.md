## 📋 El framework ISTQB (2026)

**4 niveles** × **3 streams** × **~24 certificaciones activas**

| | Core stream | Agile stream | Specialist stream |
|---|---|---|---|
| **Foundation** | CTFL v4.0 | CTFL-AT (retira may 2027) | (ninguna) |
| **Advanced** | CTAL-TA v4.0, CTAL-TTA, CTAL-TM v3.0, CTAL-TAE v2.0 | CTAL-AT v2.0, CTAL-ATT, CT-ATLaS | (ninguna) |
| **Specialist** | (ninguna) | (ninguna) | 13+ certs |
| **Expert** | CTEL-TM, CTEL-ITP | (ninguna) | (ninguna) |

**Reglas:**
- **CTFL es prerequisito para TODO lo demás.** Sin CTFL, no podés tomar ninguna otra ISTQB.
- **Foundation, Advanced, Specialist son de por vida** (no expiran).
- **Expert expira cada 7 años** (recertification).
- **Múltiple choice** para Foundation/Advanced/Specialist; **+ essays** para Expert.
- **Idioma español LATAM** disponible vía Member Boards locales.
- **Reconocimiento global:** 130+ países, 1.4M+ exams entregados, 1M+ certificados.

## 🌍 Alternativas a ISTQB

### CSTE (Certified Software Tester) — QAI Global

| | |
|---|---|
| **Body** | QAI (Quality Assurance Institute) |
| **Nivel** | Foundation-equivalent |
| **Costo** | USD 450-500 |
| **Recert** | Cada 3 años con CEUs |
| **Popularidad** | ~1/5 de ISTQB |
| **Foco** | Process compliance, SQA |

**¿Cuándo elegir CSTE sobre ISTQB?**
- Si tu empleador es US-based y lo pide
- Si quieres énfasis en process/audit (vs ISTQB más technical)
- Si quieres recertification regular (te fuerza a mantenerte actualizado)

### CSQA (Certified Software Quality Analyst) — QAI Global

- Senior-level (similar a ISTQB Advanced)
- Requisito: experiencia previa
- Costo: USD 450-500
- Para: senior QA, audit, management

### Otros (mencionados, menor reconocimiento)

- **CAST** (Certified Associate in Software Testing) — QAI nivel entry
- **IISTL** — International Institute for Software Testing Leadership
- **CMSQ** — Certified Manager of Software Quality (ASQ)

## 🎯 Recommended path (para tu grupo en Paraguay)

### Fase 1 — Foundation (Mes 1-3)
- **ISTQB CTFL v4.0** ← USTEDES ESTÁN ACÁ
- Costo: ~USD 200-300

### Fase 2 — Automation & English (Mes 4-9)
- Programming (Python o JS)
- Playwright cert o Selenium cert
- Inglés B2/C1

### Fase 3 — First ISTQB Advanced (Mes 10-15)
Elegir según interés:
- **CTAL-TA** si te gusta test design
- **CTAL-TM** si vas a ser lead
- **CTAL-TAE** si te enfocás en automation
- **CTAL-TTA** si te gusta lo técnico profundo

### Fase 4 — Specialist (Año 2)
- **CT-GenAI** (más demandado ahora)
- **CT-PT** o **CT-SEC** si vas a specialty
- **CT-AuT** si trabajás en automotive

### Fase 5 — Complementarias (Año 2-3)
- AWS Cloud Practitioner
- HashiCorp Terraform
- O vendor-specific (Playwright, k6, etc.)

### Fase 6 — Expert (Año 4+)
- CTEL-TM o CTEL-ITP
- Solo si vas a management/process improvement
