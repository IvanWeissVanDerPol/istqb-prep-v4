# 📅 Plan de Estudio ISTQB CTFL v4.0.1 — 8 Semanas

> **Para quién:** grupo de amigos Paraguay, estudio part-time (~5-6 h/semana), examen CTFL en 8 semanas.
> **Material:** este repo + syllabus oficial v4.0.1 (https://istqb.org).

---

## 🎯 Visión general

- **Horas totales:** ~42 horas en 8 semanas (≈5.25 h/semana)
- **Material:** 6 capítulos, 64 Learning Objectives, ~1135 min oficiales de instrucción
- **Práctica:** 4 quizzes (Cap 1+4 detallados, 2+3+5 compactos), 3 sample exams, deck flashcards
- **Examen:** 40 preguntas, 60 min, 65% mínimo

---

## 📊 Semana a semana

### Semana 1 — Cap 1 Fundamentals (4h)
**Por qué primero:** vocabulario base — todo el examen usa estos términos

- [ ] Descargar syllabus oficial PDF desde https://istqb.org
- [ ] Leer cap 1 completo (LO 1.1.1 → 1.5.3)
- [ ] Resumen `05_summaries/cap_01_fundamentos_v4.md`
- [ ] Quiz Cap 1 — meta ≥80% (16/20)
- [ ] Memorizar los **7 principios** (LO 1.3.1)
- [ ] Vocabulario error/defect/failure (LO 1.2.3)
- [ ] Flashcards: bloque Cap 1

### Semana 2 — Cap 2 SDLC (4h)
- [ ] Syllabus cap 2 (LO 2.1.1 → 2.3.1)
- [ ] Resumen `05_summaries/cap_02_ciclo_vida_v4.md`
- [ ] **NUEVOS v4.0:** shift-left (2.1.5), DevOps (2.1.4), retrospectives (2.1.6)
- [ ] Diferencia niveles (4 layers) vs tipos (functional vs non-func)
- [ ] **Confirmation vs Regression** (LO 2.2.3) ⭐
- [ ] Quiz Cap 2 — meta ≥80%

### Semana 3 — Cap 3 Static Testing (5h)
- [ ] Syllabus cap 3 (LO 3.1.1 → 3.2.5)
- [ ] Resumen `05_summaries/cap_03_estaticas_v4.md`
- [ ] Diferencia **walkthrough vs technical review vs inspection**
- [ ] Roles en reviews (author, moderator, reviewer, scribe, manager)
- [ ] Quiz Cap 3 — meta ≥75%
- [ ] Mini-ejercicio: participar en una review informal de un PRD

### Semana 4 — Cap 4 Test Analysis & Design (6h) 🔴 PESADO
- [ ] Syllabus cap 4 completo (LO 4.1.1 → 4.5.3) — más largo
- [ ] Resumen `05_summaries/cap_04_tecnicas_diseno_v4.md`
- [ ] **Practicar cada técnica a mano:**
  - EP: campo edad (0-150), password (8-20 char), email format
  - BVA: los mismos campos
  - Decision table: login (4 reglas)
  - State transition: ATM (4 estados, 7 transiciones)
  - Branch coverage: programa con 3 ifs
- [ ] **NUEVO v4.0:** user stories + acceptance criteria + ATDD (4.5.1-3)
- [ ] Quiz Cap 4 — meta ≥75% (23/30)

### Semana 5 — Cap 5 Managing Test (6h)
- [ ] Syllabus cap 5 (LO 5.1.1 → 5.5.1)
- [ ] Resumen `05_summaries/cap_05_gestion_v4.md`
- [ ] **NUEVOS v4.0:**
  - Test pyramid (5.1.6) — diagramarlo
  - Testing quadrants (5.1.7) — 2x2 matrix
- [ ] Risk: project vs product (5.2.2) ⭐
- [ ] Severity vs priority (5.5.1) ⭐ K3
- [ ] Defect report: completar al menos 5 reportes en papel
- [ ] Quiz Cap 5 — meta ≥75%

### Semana 6 — Cap 6 Tools + Repaso v4.0 changes (5h)
- [ ] Syllabus cap 6 (LO 6.1.1 → 6.2.1) — solo 20 min oficiales
- [ ] Resumen `05_summaries/cap_06_herramientas_v4.md`
- [ ] Beneficios vs riesgos de automation (6.2.1)
- [ ] **Repasar `09_v4_changes/CAMBIOS_v3.1_a_v4.0.1.md`** — cambios clave
- [ ] Quiz Cap 6 — meta ≥75%
- [ ] Repaso glosario NUEVOS v4.0.1 (interacción capability, flexibility, safety)
- [ ] Repaso flashcards bloque Cap 4

### Semana 7 — Simulacros (8h) 🔴
- [ ] Rendir **Sample Exam A** (40 preguntas, 60 min cronometrados)
- [ ] Analizar errores — agrupar por capítulo
- [ ] Reforzar capítulos con <80%
- [ ] Rendir **Sample Exam B**
- [ ] Rendir **Sample Exam C**
- [ ] **Meta:** ≥65% consistente los 3

### Semana 8 — Repaso final (4h)
- [ ] Repaso flashcards (todas)
- [ ] Repaso glosario completo (top 30 preguntas más probables)
- [ ] Sample Exam A otra vez (cronometrado)
- [ ] Repaso puntos débiles de las semanas 1-6
- [ ] **Rendir examen oficial**

## 🤝 Para el grupo

**Sugerencia:** armen un grupo de chat (ya lo tenés en WhatsApp) para discutir preguntas complicadas.

- Las preguntas ISTQB son densas — leer dos veces

**Idioma:** examen oficial viene en español LATAM a través de ASOLINFO.
**Tip:** usá el syllabus en inglés para familiarizarte con los términos exactos (a veces hay sutiles diferencias en cómo se traducen).
