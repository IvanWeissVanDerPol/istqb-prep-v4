## 🔍 Cómo buscar dentro del repo

**Por tema (rápido):**
- Sample exams → `06_practice_tests/sample_exam_*.md`
- Cap 4 stuff → `05_summaries/cap_04_*` + `08_quick_refs/cap_04_*`
- Career → `09_career_paths/`
- Interview → `15_interview_prep/`

**Por pregunta tipo:**
- "¿Cuál es la diferencia entre X y Y?" → buscar con grep `grep -r "diferencia" --include="*.md"`
- "Salarios PY" → `09_career_paths/README.md`
- "Cheat sheet" → `08_quick_refs/`

**Con grep (terminal):**
```bash
grep -r "ISTQB" --include="*.md" .
grep -r "v4.0" --include="*.md" . | head -20
```
