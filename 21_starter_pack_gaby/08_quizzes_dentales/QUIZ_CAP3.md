# Quiz Cap 3 — Pruebas Estáticas (versión dental)

> 8 preguntas tipo ISTQB.

---

### Pregunta 1

Un residente de odontología presenta un caso complejo en el ateneo. Los odontólogos de planta preguntan, sugieren alternativas, debaten el plan. ¿Qué tipo de revisión es?

A) Informal review
B) Walkthrough
C) Technical review
D) Inspection

<details>
<summary>Respuesta</summary>

**B) Walkthrough.** El autor (residente) presenta el documento. El grupo hace preguntas. Es la definición de walkthrough.
</details>

---

### Pregunta 2

El Círculo de Odontólogos del Paraguay realiza una auditoría donde revisa historias clínicas con un checklist estandarizado, roles definidos (auditor, auditado, observador), métricas (% historias completas), y proceso formal paso a paso. ¿Qué tipo de revisión es?

A) Informal review
B) Walkthrough
C) Technical review
D) Inspection

<details>
<summary>Respuesta</summary>

**D) Inspection.** Roles definidos + checklist + métricas + proceso formal. Esa es la definición de inspection formal.
</details>

### Pregunta 3

¿Cuál de las siguientes NO es una característica del static testing según ISTQB?

A) No requiere ejecutar el software
B) Encuentra defectos que el testing dinámico no encuentra
C) Solo se aplica a código fuente
D) Es más barato encontrar defectos tempranamente

<details>
<summary>Respuesta</summary>

**C) Solo se aplica a código fuente.** FALSO. Static testing se aplica a CUALQUIER work product: requisitos, código, planes, casos de prueba, manuales, contratos, etc.
</details>

### Pregunta 4

Ordená los tipos de revisión de menos formal a más formal:

A) Inspection → Technical review → Walkthrough → Informal review
B) Informal review → Walkthrough → Technical review → Inspection
C) Walkthrough → Inspection → Informal review → Technical review
D) Informal review → Technical review → Walkthrough → Inspection

<details>
<summary>Respuesta</summary>

**B) Informal review → Walkthrough → Technical review → Inspection.** De menos a más formal.
</details>

### Pregunta 5

Antes de firmar un consentimiento informado para un tratamiento complejo, la odontóloga se lo pasa a su colega para que lo lea y le dé su opinión. No hay roles definidos ni proceso formal. ¿Qué tipo de revisión es?

A) Informal review
B) Walkthrough
C) Technical review
D) Inspection

<details>
<summary>Respuesta</summary>

**A) Informal review.** Sin roles, sin proceso formal. Conversación entre colegas.
</details>

---

### Pregunta 6

¿Qué tipo de defecto es más probable encontrar con static testing que con dynamic testing?

A) Defectos de performance (el sistema es lento)
B) Requisitos faltantes o ambiguos
C) Defectos en el manejo de errores en runtime
D) Memory leaks

<details>
<summary>Respuesta</summary>

**B) Requisitos faltantes o ambiguos.** Estos se detectan leyendo documentos, no ejecutando. Performance y memory leaks requieren ejecución (dynamic testing).
</details>

---

### Pregunta 7

Una ventaja principal del static testing sobre el dynamic testing es:

A) Encuentra más defectos por hora
B) Encuentra defectos más temprano
C) Es más fácil de automatizar
D) Requiere menos experiencia

<details>
<summary>Respuesta</summary>

**B) Encuentra defectos más temprano.** Es la razón principal para usar static testing. Un defecto encontrado en requisitos es 100x más barato que uno encontrado en producción.
</details>

---

### Pregunta 8

En una inspection formal, ¿cuál es el rol que se encarga de leer el documento en voz alta durante la reunión?

A) Moderator
B) Author
C) Reader
D) Reviewer

<details>
<summary>Respuesta</summary>

**C) Reader.** Lee el documento. El moderator facilita, el author responde preguntas, el reviewer busca defectos, el recorder anota.
</details>
